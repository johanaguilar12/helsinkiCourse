# Phonebook

This project implements Full Stack Open exercises 2.6-2.11. The initial persons are loaded from JSON Server; adding persons is currently local to the app.

Run the API and the React app in separate terminals from this directory:

```bash
npm run server
npm run dev
```

The API serves the phonebook at `http://localhost:3001/persons`. The notes example also uses port 3001, so do not run both JSON Servers at the same time.
